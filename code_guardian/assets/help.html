Modos de Análise — VB6

Arquivo único

Analisa um único arquivo .bas, .cls, .frm ou .ctl. Use para verificar rapidamente um arquivo específico antes de entregar.

Scan de diretório

Varre todos os arquivos VB6 de uma pasta recursivamente. Exibe progresso arquivo a arquivo com tamanho (KB) e tempo de análise. Arquivos que demoram mais de 10s exibem heartbeat ⏳ ainda processando... no terminal.

⚠️ Pastas grandes (60+ arquivos) podem levar vários minutos. Use Comparação de pastas se só quiser revisar o que mudou.

Comparação de pastas

Compara duas pastas VB6 e analisa apenas os arquivos modificados ou adicionados na pasta de revisão. Usa MD5 para detectar diferenças, então arquivos idênticos são ignorados automaticamente.

  • Pasta base (original): código atual / branch de destino
  • Pasta revisão (modificada): código com as alterações (PDP, branch de revisão)
✅ Marque "Apenas linhas alteradas (diff-only)" para ver somente issues nas linhas que foram realmente modificadas — reduz drasticamente o ruído de código legado.

Comparação de arquivos

Compara dois arquivos VB6 individuais (original vs modificado). Ideal para revisar um único form ou módulo de uma entrega.

  • Arquivo original (base): versão atual do arquivo
  • Arquivo modificado (revisão): versão com as alterações
✅ Também suporta "Apenas linhas alteradas" para foco total no código novo.

Opção: Apenas linhas alteradas (diff-only)

Disponível nos modos de comparação. Usa difflib (nativo Python) para calcular quais linhas foram adicionadas ou substituídas no arquivo de revisão. Apenas issues que caem nessas linhas são reportados.

Logs e diagnóstico

Os logs de execução ficam em .codeguardian/logs/vb6-YYYY-MM-DD.log relativo ao diretório do projeto. Cada execução registra:

  • Comando executado com todos os argumentos
  • Cada arquivo analisado com score, número de issues e tempo
  • Heartbeat WARNING se um arquivo demorar mais de 10s
  • Resultado final com tempo total
Se a análise parecer travada, verifique o log — o último registro mostra qual arquivo estava sendo processado.

Uso via linha de comando (CLI)

VB6 — vb6_rule_engine.py

# Arquivo único
python vb6_rule_engine.py arquivo.frm

# Scan de pasta
python vb6_rule_engine.py --scan --dir C:/projeto

# Comparação de pastas
python vb6_rule_engine.py --compare --base C:/original --review C:/revisao

# Comparação de pastas — só linhas alteradas
python vb6_rule_engine.py --compare --base C:/original --review C:/revisao --diff-only

# Comparação de dois arquivos
python vb6_rule_engine.py --compare-files --base original.frm --review modificado.frm

# Flags comuns
--format html          # saída HTML
--format json          # saída JSON (CI/CD)
--severity error       # só critical e error
--output relatorio.html
